WebP and SVG Activity

WebP Questions

1. Original JPG File Size:
About 2.87 MB (2868 kB).

2. WebP File Size:
The WebP version is significantly smaller, usually between 300–800 kB depending on compression settings.

3. Methods to Reduce File Size Below 75 KB:

  • Crop the image to only the needed area.
  • Resize the image to the required dimensions.
  • Reduce image quality/compression level.
  • Remove unnecessary metadata.

4. Optimized Image Result:
After resizing and compressing the image, the final WebP image was reduced below 87 KB while maintaining acceptable quality.

SVG Questions

5. SVG File Size:
About 0.433 kB (less than 1 kB).

6. What does an SVG look like in a text editor?
SVG files appear as XML-style code with tags and attributes. 

<svg viewBox="0 0 24 24">
    <circle cx="12" cy="12" r="10"></circle>
</svg>

7. Shapes Used in the Icon:

  • circle
  • polyline
  • line

8. Purpose of viewBox:
Defines the coordinate system and visible area of the SVG.

Example: viewBox="0 0 24 24"

9. Purpose of fill:
Defines the inside color of a shape.

Example: fill="none"

10. Purpose of stroke:
Defines the outline color of the shape.

Example: stroke="#555"

11. Purpose of stroke-width:
Defines the thickness of the lines.

Example: stroke-width="2"

12. Purpose of stroke-linecap:
Defines the shape of the ends of lines.

Example: stroke-linecap="round"

13. Changing the Line Color:
Changing the stroke color to red successfully updated the icon color in the browser. 

stroke="#ff0000"

Icon Libraries

SVG icons are lightweight, scalable, and remain sharp at any size.

Downloading a single SVG icon is more efficient than loading an entire icon library because only the necessary vector data is loaded.

Example HTML for using an SVG icon: 

<img src="images/facebook.svg" alt="Facebook Icon">

SVG images are vector-based and do not lose quality when resized, unlike bitmap images such as JPG or PNG.
